Firmware update (car node main.py)
Checks the published release, downloads it, decrypts it on this phone and checks its SHA-256. Then enter the PIN and tap Install.
Or pick a main.py file yourself
Download main.py from GitHub (car_node/main.py), pick it here, enter the PIN, tap Install. About a minute. The box restarts with it and goes back to the old one if it crashes.
The GPS LED blinking once a second means the module has a fix. If this page then shows 0 bytes/s, the wire from GPS TX to the box is the problem.
